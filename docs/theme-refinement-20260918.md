# iOS画面のテーマ調整（2026-09-18）

## 利用者の指定に基づく変更

- トップの大きなKIROKUNアイコンを廃止。従来約223ptの領域を約120ptの横幅いっぱいのコーラル色ヘッダーへ変更。
- Proto / Dev の名称と概要、ランダムな応援文を表示。応援文は画面生成時に3候補から選び、閲覧中に自動で入れ替えない。日本語・英語の言語ファイルで管理。
- 回答率の円グラフ・達成度メッセージと従来の集計方法は維持。
- 一覧は行単位で白／淡いコーラルを交互に使用。未回答は濃いコーラル、回答済みはグレー。状態の文字表示も残し、色だけに依存しない。
- 回答画面はプロジェクト名を載せたコーラル色ヘッダーに統一。開始画面のデフォルトアプリアイコンを除去。
- 設問アイコンは種類に対応した標準シンボルをテーマ色で描画し、元の位置・サイズを維持。
- 使い方／このアプリについて／連絡先／回答履歴のヘッダーも統一。本文は黒系、リンクや見出しはテーマ色。閉じるボタンはiOS 26ではGlass、透明度低減時・旧OSでは通常表示。
- Devだけに適用していた回答画面のテーマをProtoにも適用。認証方式・接続先は変更しない。

## 検証と範囲

Devの既存回答は変更せず、未回答の合成テスト04を1件追加。4件中3件の回答率75%を確認。
開始画面・自由記述画面のレイアウトを確認し、回答は送信せず閉じた。
今回の対象はiOS。プロジェクト概要・応援文を管理画面から編集する機能やAndroidへの同等変更は含めない。

DevDebugとProtoDebugの最終ビルド成功。日本語でホーム／回答開始／自由記述／使い方／連絡先／このアプリについてをシミュレーター確認。ランダム文の切り替わりも再起動で確認。最終の回答開始ボタンは黒文字で表示されることを確認。
