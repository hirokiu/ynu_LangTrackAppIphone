# iOS端末・OS別確認（2026-09-18）

## 対象と限界

アプリの最低対応OSはiOS 17.6。インストール済みの17.5は対象外で、Appleへの`xcodebuild -downloadPlatform iOS -buildVersion 17.6`は「iOS 17.6 is not available for download」となった。対応OSの設定を下げず、入手済みで対応範囲内の最古である18.0を代替対象にした。17.6そのものの確認は未完了。

最新はこのMacにインストールされているiOS 27.0（24A434）を使用。一般公開の安定版としての認定を意味しない。

## 検証内容

各実行先のUIScreenサイズで本体のSurveyViewControllerと実際のStoryboardをロードし、開始・7形式・最終確認のページを表示。各形式の前へ／次へ／送信、および5件法の全選択肢が表示領域をはみ出さないことを検証した。追加でSEの内容領域におけるリッカートの両端説明、日付解析の既存2件を実行した。

別途、iOS 27のSEで未回答・回答済みモーダルの値のX座標一致、白文字、アイコン由来の背景色を検証し成功した（計17件）。レイアウトの自動検証は、全操作の目視テストやFirebase認証・通知・送信の結合テストの代替ではない。

## 発見と修正

- SE / iOS 18で自由入力欄がソフトウェアキーボードに隠れたため、入力中は設問と入力欄のブロックをキーボードの上へ移動。装飾アイコンと下部ボタンは入力中に隠し、入力終了時に復帰。修正後の設問と入力欄の表示を目視確認済み。
- 未回答ポップアップの青色をKIROKUN色へ変更。iOS 26以降はGlass効果、古いOS・透明度を下げる設定では通常のテーマ色を使用。
- 未回答・回答済みの質問数と日付の値を同じ行頭に統一。開始画面の公開日・回答期限も2列で行頭を統一。
- 回答済みモーダルは入れ子のヘッダーにもテーマを適用し、白文字に統一。
- 未回答ポップアップの質問数から開始・終了ページを除外。

## 再現用表示モード

DevDebugかつシミュレーターだけで`--layout-preview`を指定すると、端末内の7形式のSurveyを表示する。送信操作は端末内の完了表示に置き換え、APIには送らない。Proto、実機、Releaseでは無効。

- `--preview-page=2`：5件法から表示
- `--preview-unanswered`：未回答ポップアップ
- `--preview-answered`：回答済みモーダル

認証済みの確認用端末や実データを複製せず、各OS・端末で同じフォームを再現するための機能。テスト対象は本体と同じ画面部品・コントローラー。

## 残る確認

Macのロックにより目視操作が中断。新旧OSでのポップアップの外観、入力終了後の操作、一連の回答・最終確認スクロール、文字サイズ拡大時の長文は追加確認が必要。iOS 17.6そのものとPush通知は未検証。

修正後のProtoの署名付きビルドと、接続済みiPhone 11 Proへの更新インストールは成功。
