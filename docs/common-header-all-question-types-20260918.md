# 共通ヘッダーと全設問形式の確認（2026-09-18）

## 画面

- トップに白いKIROKUN共通ヘッダーを復元。その下に中央揃えのプロジェクト名・概要・応援文を表示。
- 回答画面はKIROKUN共通ヘッダー、その下にアンケート名・設問番号・入力条件のヘッダーを配置。
- 開始画面はアンケート名、全設問数、公開日、回答期限を表示。日付は割当データの公開日時・期限を端末のローカル時刻で表示。
- 設問番号はindexそのものではなく、index順に並べた設問の表示順。開始・終了ページを分母から除外。条件分岐で飛ばされる設問も全体数には含める。
- 回答済み詳細のアプリアイコンを非表示にし、設問種類の緑アイコンをテーマ色のシンボルへ変更。
- 複数の未回答Surveyを識別できるよう、トップの回答カードにもSurvey名を表示。

## 入力条件の表示

現行のデータモデルには設問ごとのrequiredフラグがない。今回の表示は既存の入力条件を表し、新しい必須判定や研究データのスキーマ変更は行わない。

|形式|表示する条件|
|---|---|
|自由入力|任意|
|5件法|選択必須|
|単一選択|選択必須|
|複数選択|1つ以上選択必須|
|空欄補充|選択必須|
|スライダー|初期値50、該当なしも選択可能|
|時間入力|初期値0時間0分|

検証中、スライダーを動かしても親画面の回答が更新されない既存処理を発見した。値変更時、および次へ／前へ移動前に実際のスライダー値と該当なし状態を回答へ反映するよう修正。
