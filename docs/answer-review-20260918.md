# 送信前の回答確認と状態表示（2026-09-18）

## 変更内容

- トップの回答済み行は従来の緑の印を復元。未回答はテーマ色のアイコンと「未回答」で識別できる。
- チェックボックス、ラジオボタン、5件法の選択色をKIROKUNのテーマ色に統一。
- 最後の画面に設問と実際の回答を表示。「前へ」で修正可能。送信ボタンは「回答を送信」に変更。
- 選択肢は内部番号ではなく項目名、5件法は1〜5、時間は時間・分で表示。自由入力、該当なし、任意の未入力にも対応。
- 確認画面と送信処理は同じ設問抽出処理を使用し、分岐経路から外れた回答を含めない。
- 日本語・英語の言語ファイルを更新。

## 検証

DevDebug / ProtoDebugのビルド成功。iOSシミュレーターのDev環境で、動作テスト用Surveyの7形式を回答し、確認画面の内容と送信後のDBの7件が一致することを確認した。

|形式|確認・保存した回答|
|---|---|
|自由入力|送信前の確認テスト|
|5件法|3 / 5（内部値2）|
|単一選択|日本語|
|複数選択|読む、聞く|
|空欄補充|単語|
|スライダー|75 / 100|
|時間入力|0時間0分|

送信後のトップで回答率更新、回答済みの緑の印、残る未回答の文言とアイコンを確認。回答済み詳細も確認した。

「全入力形式の確認（利用者確認用）」は未回答で残している。変更・回答テストの対象はDevのみで、Protoと旧本番のデータは変更していない。実機確認は別途必要。
